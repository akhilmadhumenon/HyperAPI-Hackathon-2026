Financial Gauntlet Engine

AI-Driven identification & Forensic Analysis

Team baby_sharks
Mission Objective

Build a high-precision document intelligence pipeline to detect 20 categories of financial inconsistencies (“needles”) within a 1,000-page dataset.

  • Scale: 1,000 pages, 750 documents, 200 deliberate errors.
  • Precision: Zero-tolerance for false positives (-0.5 point penalty).
  • Speed: Aggressive caching to bypass API bottlenecks.
System Architecture

A hybrid engine separating Inference from Validation.

PDF -> Deterministic Splitting -> HyperAPI Extraction -> Normalization -> SQLite Relational DB -> SQL Validation Engine -> Submission JSON

By transforming messy pixels into a Relational Database, we treat fraud detection as a Data Query problem.

Winning Strategies
